How to use

  1. Pick a styleChoose bold, italic, small caps, monospace, or another option.
  2. Write or pasteText converts as you type, and the editor grows with your message.
  3. Style a selectionHighlight any part of your text, select a style, then press Apply Style.
  4. Copy and shareCopy the result and paste it into Facebook, Messenger, captions, or comments.

Helpful tips

  • Select all or CTRL-A to change all text into one font.
  • You can select specific texts you want to change the font into or start using the font once selected.
  • Use Reset to return selected text to regular characters.
  • Some symbols may look different across devices and platforms.
